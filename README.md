# 天衣 · 无缝的江湖

一个纯文字放置武侠，单文件网页游戏。开 `index.html` 就能玩，不用装任何东西。
世界观、门派、武学、人物、剧情皆为原创。玩法上向《放置江湖》致意。

十年前洛水断流七日。天下会武功的人做了同一个梦，梦里有个白发女人在缝东西。
第七日夜里河又通了，三千零一十七名高手死在床上，身上没有一处伤，
嘴里各有一根一寸长的银线。而你在那七日之后醒来，忘了十年。

## 这一版改了什么

原来的江湖是：一个四方罗盘、一张格子表、一个「往下走」的钮。
走路是瞬移，地图是列表，剧情是点按钮。这三件事都重做了。

### 行路

- 两地之间有距离。走要时候，脚程按身法与捷算。
- 可缓行（路上见闻多）可疾行（快而少事），半路上也可以不走了。
- 路分官道、山道、野径、水路、地缝，快慢与出事的机会各不相同。
- 路上会撞见事：遇敌、奇遇、见闻、拾遗，或者望见一条没走过的岔道。
  撞见事就停下来，了结了再接着走。
- 赶路本身是练功——脚底下的功夫，本来就是走出来的。

### 一处地方底下的去处

- 每一处地方分成几个「去处」：船头、苇滩、酒肆、井台、机房、钟楼……
- 活计认去处：药在坡上，铁在砂里，丝在机房。要做哪一桩，先走到那儿。
- 人也站在去处上，且各有各的时辰——裴无咎掌灯之后才在馄饨摊，
  释寒山白天在钟楼。赶不上就见不着。
- 搜是一处一处地搜，每个去处各藏一桩。

### 舆图

- 主界面下半屏是一张画出来的图：洛水、地势、针脚一样的路。
- 你自己是那个金环；走着的时候，图上那个点是动的。
- 听人说过、还没走通的地方是虚的；只看得见方向的是一个问号。
  走到路口上「探路」，通不通看火候、缘法和试过几回。
- 图上标着谁在跟前、哪儿还有东西没搜出来。
- 一条朱线牵着当前线索该去的地方。

### 剧情

- 没有「往下走」可点。十章各有各的触发条件：某处、某个去处、
  某个时辰、某个火候、某件事做过了——凑齐了，事情自己找上来。
- 「纪事」是线索板：一句话、一个地名、一个时候，还差什么摊开给你看。
- 不知道该往哪儿去，就在集上、酒肆、馄饨摊「打听」，或者去问渡老。
- 到了地方却不是时候，江湖会轻轻提你一句。

### 另外

- 一日五个时辰：拂晓、晌午、黄昏、入夜、子时。谁在不在、夜路好不好走，
  都看天色。
- 交手不再打在幕布后头——从前点了「动手」，仗其实是在盖着的窗子底下打完的。
- 没有 `window.storage` 时退回浏览器本地存档，单独一个文件也存得住。
- 新加「怎么走」一页（设置里随时可看）。

## 玩

```
open index.html
```

功夫关掉网页也不停。离线回来会告诉你这段时候长了多少，
路也会自己走完。

## 目录

- `index.html` —— 游戏本体，一个文件，包括现算的琴声与响动（没有一个音频文件）。
